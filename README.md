# 👥 CRUD Lista de Funcionários


Uma aplicação fullstack completa para gerenciamento de pessoal, permitindo criar, ler, atualizar e deletar registros em um banco de dados relacional.

## 🛠 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

*   **Frontend:** HTML5, CSS3 e JavaScript (ES6+).
*   **Backend:** Node.js com Express.
*   **Banco de Dados:** MySQL.
*   **Design:** Layout totalmente **responsivo** (Mobile First).

## 🚀 Funcionalidades

- [x] **C**reate: Cadastro de novos funcionários com validação.
- [x] **R**ead: Visualização da lista atualizada em tempo real.
- [x] **U**pdate: Edição de dados existentes.
- [x] **D**elete: Remoção de registros com confirmação.
- [x] **Interface Adaptável**: Visualização otimizada para celulares, tablets e desktops.

## 📥 Como executar o projeto

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    ```
3.  **Configure o Banco de Dados:**
    *   Importe o arquivo `database.sql` no seu MySQL.
4.  **Inicie o servidor:**
    ```bash
    npm start
    ```
